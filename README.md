# 📦 Sistema de Inventario – Python & SQLite

**Autora:** Andrea Kohn

## 📋 Descripción

Sistema de gestión de inventario desarrollado en Python, utilizando SQLite como sistema de base de datos.

El proyecto permite administrar productos, almacenar su información y consultar los registros guardados.

## 🛠️ Tecnologías utilizadas

- Python 3
- SQLite3
- SQL
- Visual Studio Code
- Git y GitHub

## ⚙️ Estructura de la base de datos

Base de datos: `inventario.db`

Tabla: `productos`

| Campo | Tipo | Descripción |
|---|---|---|
| id | INTEGER | Identificador único |
| nombre | TEXT | Nombre del producto |
| descripcion | TEXT | Descripción |
| cantidad | INTEGER | Stock disponible |
| precio | REAL | Precio |
| categoria | TEXT | Categoría |

## 🚀 Funcionalidades

- Agregar productos.
- Mostrar todos los productos.
- Buscar productos por ID.
- Almacenar información permanentemente en SQLite.
- Menú interactivo en consola.

## 💻 Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/25950032/Sistema-Inventario-Python.git
```

2. Ingresar a la carpeta:

```bash
cd Sistema-Inventario-Python
```

3. Ejecutar el programa:

```bash
python menu_inventario.py
```

## 📌 Menú principal

1. Agregar producto.
2. Mostrar productos.
3. Buscar producto.
4. Modificar producto.
5. Eliminar producto.
6. Salir.
